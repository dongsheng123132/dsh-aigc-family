# dsh-t2i

DeepSeek Harness 的**文生图**插件。`t2i` = text-to-image（对应 `i2i` 图生图、`t2v` 文生视频）。

```bash
dsh plugin add dsh-t2i
```

| 工具 | 干什么 | 价格 |
|---|---|---|
| `dsh_t2i_generate` | 一句描述出图，落本地 PNG | **¥0.03 / 张**（默认 `gpt-image-2.6-1k`） |

尺寸可写像素（`1024x1536`）或比例（`3:4` / `16:9`，自动换算）。一次 1–4 张。

## 用之前

需要一个虾盘云钱包（按次扣费）：设 `XIAPAN_API_KEY=sk-...`，或写进 `~/.dsh/aigc-wallet.json`。

## 例子

> 用 dsh_t2i_generate 画一张「凌晨两点的便利店，暖黄灯光，胶片感」，比例 3:4

落到 `~/Downloads/dsh-t2i/`。

## 报错怎么读

| 报错 | 真正原因 | 怎么办 |
|---|---|---|
| `这个模型没给这把密钥开权限` | 白名单没开 | 发模型名给客服，别换密钥 |
| `余额不足` | 没钱了 | 充值 |
| `凭证无效或已失效` | 余额透支也会这样 | 先查余额 |
