# dsh-poster

DeepSeek Harness 的**海报 / 封面 / 缩略图**插件：选画幅预设，一次出图。

```bash
dsh plugin add dsh-poster
```

| 预设 | 画幅 | 适合 |
|---|---|---|
| `poster` | 1024×1536 竖版 | 活动海报、宣传图 |
| `cover` | 1024×1024 方形 | 专辑/播客封面 |
| `thumb` | 1536×1024 横版 | 视频缩略图 |
| `banner` | 1536×1024 横版 | 页头主视觉 |
| `wallpaper` | 1024×1536 | 手机壁纸 |

价格 **¥0.03/张**（`gpt-image-2.6-1k`）。

> `text` 参数只是**让画面留白**给后加标题，不会把字画进图里——AI 画中文字不可靠，留白再排版更稳。
